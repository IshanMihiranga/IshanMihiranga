## 👨‍💻 About Me

I'm **Ishan Mihiranga**, a **Full Stack Developer** from Sri Lanka.

I'm a **Software Engineering undergraduate** at **IIC University of Technology** and I'm also studying at the **Java Institute for Advanced Technology (JIAT)**. I build full stack **web and mobile applications** with **Java, Spring Boot, React and React Native**, using **MySQL, PostgreSQL and Firebase** for data.

I'm passionate about **Artificial Intelligence** and **Cloud Computing**, and I work with **AWS** to deploy and scale applications.

- 🌱 I'm currently learning **AWS Cloud and AI**
- 💬 Ask me about **Java, Spring Boot, React, REST APIs, Microservices & Full Stack Development**
